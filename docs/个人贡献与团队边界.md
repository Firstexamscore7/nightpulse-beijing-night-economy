# 个人贡献与团队边界

## 团队背景

原调研项目由五人团队完成。当前匿名作品集按用户确认的信息表述为：团队核心参与者、成果署名第三顺位。署名顺序只表示署名排列，不作为贡献程度排名。

## 原项目参与环节

个人参与了研究设计、问卷实施、数据清洗、统计分析、模型训练、报告撰写、PPT 制作、现场答辩和政府沟通等工作。以上为团队项目中的个人参与，不表示全部成果由个人独立完成。

## 本次作品集重构

本次新增并由个人主导整理的部分包括：

- 对照原始数据和旧清洗表，建立数据质量审计与明确口径；
- 重建可复现的数据处理和模型分析流程；
- 补充样本敏感性、基线模型、特征对照和局限说明；
- 将调查发现整理为面向活动运营团队的决策看板原型；
- 形成匿名版项目简介、交付说明和外部结构化评审材料。

## 对外表述边界

- 可以说“参与”“负责其中的……”或“主导本次作品集重构”。
- 不说“个人独立完成整个竞赛项目”或“个人独立获得团队奖项”。
- 不把模型关联写成因果效果、真实客流提升或个人级精准预测。
- 不把报告采纳证明表述成政府采用了 Dashboard、AI 产品或商业方案。
